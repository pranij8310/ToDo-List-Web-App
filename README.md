
# 📝 To-Do List Web App

A modern and visually appealing **To-Do List Web Application** built using **HTML, CSS, and JavaScript** that helps users manage daily tasks efficiently.

## ✨ Features

* Add new tasks easily
* Mark tasks as completed (strike-through effect)
* Delete tasks instantly
* Smooth UI animations for adding, completing, and removing tasks
* Data saved in **LocalStorage** so tasks remain after page refresh
* Clean, responsive, and user-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox, animations, modern UI styling)
* JavaScript (DOM manipulation & LocalStorage)

## 🚀 How to Use

1. Enter a task in the input field
2. Click **Add Task
3. Mark tasks as complete or delete them anytime
4. Refresh the page — your tasks will still be saved

## 📌 Purpose

This project was created to practice **front-end development, DOM handling, and browser storage**, and serves as a beginner-friendly portfolio project.
